# Les documents de l'application d'origine

Ce dossier conserve la documentation d'[A2Tools DPS
Meter](https://github.com/taengu/A2Tools-DPS-Meter), dont ce programme est une
version modifiée.

Elle est **gardée, pas supprimée** : la GPL-3.0 demande de conserver les
mentions d'origine, et ces pages disent ce que faisait le programme avant nos
modifications. Elles ne décrivent plus exactement celui-ci.

| Fichier | Quoi |
|---|---|
| `README-A2Tools.md` | Le README d'origine, en anglais |
| `README-A2Tools_KO.md` | Sa traduction coréenne |
| `README-A2Tools_ZH.md` | Sa traduction en chinois simplifié |
| `README-A2Tools_ZH-TW.md` | Sa traduction en chinois traditionnel |

Pour ce que fait **cette** version, voir le [README](../../README.md) à la
racine et [LISEZ-MOI-XIIINRV.md](../../LISEZ-MOI-XIIINRV.md).

## Retiré au passage

`.github/FUNDING.yml` a été supprimé. Il faisait afficher par GitHub un bouton
« Sponsor » sur ce dépôt, pointant vers le Ko-fi, le PayPal et le compte de
paiement de l'auteur d'origine. Sur un dépôt public, un membre y aurait vu la
guilde solliciter des dons pour un tiers.

La licence n'exige rien de tel : ce qu'elle exige est l'attribution d'auteur,
qui est dans le README, dans le copyright du paquet et dans les fichiers
source.
